# Chicago Crime Data Analysis (2008–2011)

Exploratory analysis of Chicago crime data using Python.

### Objectives
- Clean and explore crime records.
- Analyse crime patterns by time, district, and location.
- Examine arrest rates.
- Visualise key findings.

### Tools
Python | Pandas | NumPy | Matplotlib | Jupyter Notebook

### Dataset
[Chicago Crime Dataset (2008–2011)](https://github.com/lrnv/inf-prof/blob/main/4_project/Chicago_Cimes_2008_to_2011.csv)

### How to Run
Open the Jupyter Notebook in Google Colab or Jupyter and run the cells.
